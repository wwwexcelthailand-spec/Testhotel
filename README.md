# ระบบจัดการห้องพัก (The Retford Residence - Owner Admin Suite)

เว็บแอปพลิเคชันบริหารจัดการห้องพักสำหรับเจ้าของคนเดียว รองรับทั้งการเช่ารายวันและสัญญารายเดือน ภาษาไทย ใช้งานได้ลื่นไหลทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ ข้อมูลทั้งหมดเก็บอยู่ในเครื่อง (`SQLite + Prisma`)

## สไตล์การออกแบบ
- อ้างอิงโทนสีและบรรยากาศจาก **Rooms at the Inn Retford**: พื้นหลังขาวสะอาด (`#FFFFFF`) และเทาอ่อน (`#FAFAFA`), สีเน้น **Royal Plum (`#5c2484`)**, ฟอนต์หัวข้อ `Cormorant Garamond` + `Noto Serif Thai` คู่กับฟอนต์เนื้อหา `Noto Sans Thai`
- ตารางและการ์ดอ่านง่าย สะอาดตา ไม่มีโฆษณา ไม่เชื่อมต่อภายนอกที่ไม่จำเป็น
- รูปถ่ายห้องพักฟรีจาก **Unsplash** (Free to use under the Unsplash License)

## วิธีติดตั้งและรันบนเครื่องตัวเอง (Local Setup)

1. **เข้าไปที่โฟลเดอร์โปรเจกต์**
   ```bash
   cd C:\Users\arisa\.gemini\antigravity\scratch\room-manager
   ```

2. **ติดตั้งแพ็กเกจ**
   ```bash
   npm install
   ```

3. **สร้างฐานข้อมูล SQLite และเติมข้อมูลตัวอย่าง 10 ห้อง**
   ```bash
   npx prisma db push
   npm run seed
   ```
   *(หากต้องการลบข้อมูลตัวอย่างทั้งหมดด้วยคำสั่ง CLI รัน `npm run seed:clear` หรือกดปุ่ม **"ลบข้อมูลตัวอย่างทั้งหมด"** ในหน้า **ตั้งค่า & Backup** ได้ทันที)*

4. **รันเซิร์ฟเวอร์สำหรับใช้งาน**
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

5. **รหัสผ่านเข้าสู่ระบบเริ่มต้น (Single Admin)**
   - รหัสผ่านเริ่มต้น: `admin1234` (คลิกที่รหัสผ่านบนหน้าล็อกอินเพื่อกรอกอัตโนมัติได้)
   - สามารถเปลี่ยนรหัสผ่านได้ที่เมนู **ตั้งค่า & Backup**

6. **รันชุดทดสอบ (Unit Tests)**
   ```bash
   npm test
   ```

## ฟังก์ชันและหน้าการทำงานของระบบ (ครบถ้วนทุกเฟส 1 - 3)

### 1. แดชบอร์ดภาพรวม (`/`)
- สรุปคิวเช็คอินวันนี้ (14:00 น.), เช็คเอาท์วันนี้ (ก่อน 12:00 น.), ห้องว่าง, รายได้รวมเดือนนี้ (แยกรายวันและรายเดือน)
- แจ้งเตือนบิลรายเดือนค้างชำระ พร้อมค่าปรับล่าช้าอัตโนมัติ (วันละ 50 บาท)
- แจ้งเตือนสัญญารายเดือนที่ใกล้หมดอายุ (ภายใน 30 วัน หรือตามที่ตั้งค่าไว้)
- ผังห้องพักทั้งหมด 10 ห้อง สามารถคลิกเปลี่ยนสถานะห้องด่วนได้ทันที (ว่าง / มีผู้พัก / จองแล้ว / ทำความสะอาด / ซ่อมบำรุง)

### 2. ปฏิทินห้องพักลากวาง (`/calendar`)
- แสดงห้องพักแนวตั้ง วันที่แนวนอน 14 วัน (เลื่อนไป-กลับได้)
- แยกสีชัดเจน: รายวันเช็คอินแล้ว (สีม่วง), รายวันรอเช็คอิน (สีน้ำเงิน), สัญญารายเดือน (สีดำเทาพร้อมไอคอนล็อก)
- **ลากวาง (Drag & Drop):** ลากแถบเพื่อย้ายห้องหรือเปลี่ยนวัน, ลากขอบขวาเพื่อเพิ่ม/ลดจำนวนคืน
- **ป้องกันการซ้อนทับอัตโนมัติ:** บล็อกห้องที่มีสัญญารายเดือน และห้ามจองทับคิวอื่น (แต่อนุญาตให้ออกก่อน 12:00 วันเดียวกับคนใหม่เข้า 14:00 ได้)
- คลิกช่องว่างบนปฏิทินเพื่อเปิดหน้าต่างจองรายวันด่วน

### 3. จัดการห้องพัก (`/rooms`)
- เพิ่ม, แก้ไข, ลบห้องพัก กำหนดเลขห้อง, ชื่อห้อง, ชั้น, ราคารายวัน, ราคารายเดือน, รูปภาพห้องพัก และสถานะห้อง

### 4. การจองรายวัน & ใบเสร็จ (`/bookings`)
- สร้าง/แก้ไขการจองรายวัน, เช็คอิน (ปรับสถานะห้องเป็น `OCCUPIED`), เช็คเอาท์ (ปรับสถานะห้องเป็น `CLEANING`)
- บันทึกเงินมัดจำ, เพิ่มค่าใช้จ่ายเสริมระหว่างเข้าพัก (มินิบาร์, เตียงเสริม, ค่าปรับออกเกินเวลา)
- สั่งพิมพ์ใบเสร็จรับเงินหรือบันทึกเป็น PDF สไตล์มินิมอล

### 5. สัญญารายเดือน (`/leases`)
- จัดการสัญญาเช่ารายเดือน: ชื่อผู้เช่า, เลขบัตรประชาชน, เบอร์โทร, LINE ID ผู้เช่า, วันเริ่ม/สิ้นสุดสัญญา, ค่าเช่า, เงินประกัน
- แนบไฟล์สัญญาเช่า / สำเนาบัตรประชาชน (อัปโหลดและดาวน์โหลดดูได้)
- แจ้งเตือนสัญญาใกล้หมดอายุ
- **ระบบย้ายออก (Move-Out):** คำนวณเงินประกันคืนอัตโนมัติ โดยหักบิลค้างชำระและค่าความเสียหาย/ทำความสะอาด พร้อมปรับสถานะห้องเป็น `ทำความสะอาด` โดยอัตโนมัติ

### 6. จดมิเตอร์น้ำ-ไฟรายเดือน (`/meter`)
- มี **โหมดการ์ดเดินจดบนมือถือ (Mobile Step-by-Step)** และ **โหมดตารางรวม (Full Table View)**
- ดึงเลขมิเตอร์เดือนก่อนหน้ามาแสดงเทียบอัตโนมัติ
- คำนวณจำนวนหน่วยน้ำและหน่วยไฟ พร้อมคำนวณจำนวนเงินตามอัตราที่ตั้งไว้ทันทีแบบ Real-time
- ปุ่มบันทึกมิเตอร์ทั้งหมดในคลิกเดียว (อัปเดตยอดลงในบิลเดือนนั้นโดยอัตโนมัติ)

### 7. บิลรายเดือน & การชำระเงิน (`/invoices`)
- ปุ่ม **"สร้างบิลเดือนนี้ทั้งหมด (Batch Generate)"** ในคลิกเดียว หรือสร้างบิลรายห้องแบบกำหนดเอง
- รวมค่าเช่า + ค่าน้ำ + ค่าไฟ + ค่าใช้จ่ายอื่นๆ พร้อมคำนวณค่าปรับล่าช้าอัตโนมัติ (วันละ 50 บาท)
- **ระบบส่งบิล LINE ตรงรายบุคคล (Direct LINE Chat):**
  - ปุ่ม **"เปิดห้องแชตผู้เช่าโดยตรง"** เปิดแชต LINE ของผู้เช่าคนนั้นทันที พร้อมคัดลอกข้อความบิลเข้าคลิปบอร์ดให้พร้อมกดวาง (Ctrl+V) ได้ทันที
  - สามารถพิมพ์บันทึก LINE ID ของผู้เช่าได้ทันทีจากในหน้าต่างส่งบิล (ไม่ต้องสลับหน้า)
  - ปุ่ม **"เปิดแอป LINE เพื่อส่ง"** (LINE Share) และปุ่ม **"คัดลอกข้อความบิล"**
- **PromptPay QR Code:** สร้าง QR Code พร้อมเพย์ตามยอดคงค้างจริงในบิล สแกนจ่ายผ่านแอปธนาคารได้ทันที
- สั่งพิมพ์ใบแจ้งหนี้ / ใบเสร็จรับเงิน หรือบันทึกเป็น PDF
- บันทึกการรับชำระเงิน (เต็มจำนวน หรือชำระบางส่วน)

### 8. ทะเบียนผู้เข้าพัก & ผู้เช่า (`/guests`)
- ทะเบียนข้อมูลติดต่อผู้เข้าพักและผู้เช่าทั้งหมด (เบอร์โทร, LINE ID, บัตรประชาชน)
- ค้นหาด้วยชื่อ เบอร์โทร หรือเลขบัตรประชาชน
- แนบเอกสารบัตรประชาชน/พาสปอร์ต
- ดูประวัติการเข้าพักย้อนหลังทั้งหมด (ประวัติสัญญารายเดือน และประวัติการจองรายวัน)

### 9. รายงานผลประกอบการ & ส่งออก Excel (`/reports`)
- รายงานรายได้รวม, สัดส่วนรายได้ (รายวัน, ค่าเช่ารายเดือน, ค่าน้ำ, ค่าไฟ, ค่าปรับ)
- กราฟแนวโน้มรายรับย้อนหลัง 6 เดือน
- **อัตราการเข้าพัก (Occupancy Rate):** คำนวณร้อยละการเข้าพักรวม และจำแนกรายห้อง
- รายการลูกหนี้และยอดค้างชำระ (Overdue Receivables)
- **ปุ่มส่งออก Excel (.xlsx):** ส่งออกรายงานครบ 4 ชีท (สรุปภาพรวม, การจองรายวัน, บิลรายเดือน, ยอดค้างชำระ) ออกแบบตารางสวยงามด้วยโทนสี The Retford

### 10. ตั้งค่าระบบ & ระบบสำรองข้อมูล Backup (`/settings`)
- กำหนดชื่อที่พัก, ที่อยู่, เบอร์โทร, เลข PromptPay
- กำหนดอัตราค่าน้ำประปา, ค่าไฟฟ้า, ค่าปรับจ่ายล่าช้า (50 บาท/วัน)
- กำหนดเวลาเช็คอิน (`14:00`) / เช็คเอาท์ (`12:00`) และจำนวนวันแจ้งเตือนสัญญาก่อนหมด
- **รูปภาพหน้าเข้าสู่ระบบ (Login Background Image):** อัปโหลดภาพห้องพักของคุณจากเครื่อง หรือระบุ URL พร้อม Live Preview และธีมบูทีคสำเร็จรูป
- เปลี่ยนรหัสผ่าน Admin
- **ระบบ Backup & Restore:**
  - ปุ่มส่งออกข้อมูลสำรอง (`.json`) ครบทุกตาราง
  - ปุ่มดาวน์โหลดไฟล์ฐานข้อมูล SQLite (`.db`) ตรงๆ
  - ส่วนนำเข้าและกู้คืนข้อมูล (Import & Restore) พร้อมระบบ **Safety Auto-Backup** เก็บข้อมูลเดิมไว้ใน `prisma/backups/` ให้อัตโนมัติก่อนเริ่มกู้คืนเสมอ
  - ปุ่มลบข้อมูลตัวอย่าง 10 ห้อง หรือรีเซ็ตข้อมูลตัวอย่างกลับมาใหม่

### 11. สลับธีม สว่าง / มืด (Dark Mode & Light Mode)
- ปุ่มสลับธีมรูปดวงจันทร์/ดวงอาทิตย์ อยู่ที่มุมบนขวามือทุกหน้าจอ (ทั้งหน้าแอดมินและหน้าล็อกอิน)
- จดจำการตั้งค่าธีมลงในเครื่องอัตโนมัติ (LocalStorage + System Preference fallback)
